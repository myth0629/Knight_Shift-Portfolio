# Knight Shift

3D 액션 전투에 로그라이트식 노드 진행을 결합한 액션 RPG 프로젝트입니다. 전투·상점·캠프·보스로 구성된 절차적 맵을 선택해 진행하며, 실시간 전투에서는 Lock-On 카메라와 상태 기반 플레이어 제어로 액션성을 유지하도록 설계했습니다.

3인 팀 프로젝트에서 메인 클라이언트를 맡아 전투 흐름, Lock-On 카메라, 플레이어 상태 관리, Firebase 로그인·데이터 연동과 랭킹 시스템을 담당했습니다.

## 핵심 구현

- **Cinemachine 기반 Lock-On 카메라**: 범위 내 최단거리 적을 선택하고 전용 가상 카메라의 우선순위를 조절해 자연스럽게 전환했습니다. 락온 카메라의 방향을 플레이어 카메라 회전에 동기화해 이동 입력과 시점이 어긋나지 않도록 했습니다.
- **절차적 노드 맵**: 레이어별 그래프 구조로 전투·상점·캠프 노드를 생성하고, 같은 레이어의 노드 유형 중복을 제한했습니다. 보스 직전에는 캠프 또는 상점이 나오도록 보정해 진행 흐름을 안정화했습니다.
- **Firebase 로그인·데이터 연동**: Firebase Authentication과 Realtime Database로 계정, 플레이어 진행, 랭킹 데이터를 관리했습니다. 비동기 로그인과 데이터 로딩 흐름을 분리해 인증 완료 전 데이터 접근을 막았습니다.
- **애니메이터 기반 전투 상태 제어**: `StateMachineBehaviour`에서 애니메이션 진행률을 기준으로 이동 잠금과 콤보 판정을 제어하고, 상태 종료 시 무기 콜라이더를 비활성화해 공격 판정이 남는 문제를 방지했습니다.

## 저장소 공개 범위

이 저장소는 포트폴리오를 위한 **코드 중심 공개 버전**입니다. 원본 프로젝트에 유료 및 제3자 모델·애니메이션·텍스처·음원·폰트·VFX·SDK와 데모 씬이 여러 경로에 포함되어 있어, 이를 전체 Git 기록에서 제외했습니다.

- 이 저장소만으로는 Unity 프로젝트를 실행할 수 없습니다.
- 팀이 작성한 게임 로직, AI, 상점·장비 데이터와 프로젝트 설정은 커밋 기록과 함께 유지했습니다.
- 원본 프로젝트 저장소는 비공개로 유지합니다.

## 주요 기술과 선택 이유

- **Unity 6 / C#**: 3D 전투, UI, 게임 상태를 컴포넌트 기반으로 나누어 구현하기 위해 사용했습니다.
- **URP**: 3D 씬의 렌더링과 품질 설정을 일관되게 관리하기 위해 선택했습니다.
- **NavMesh + 행동 트리**: 일반 몬스터와 보스가 이동 가능한 경로를 따라 추적하고, 상태별 전투 패턴을 분리하기 위해 사용했습니다.
- **Firebase Authentication / Realtime Database**: 로그인, 계정 데이터, 재화와 랭킹 정보를 게임 로직과 분리해 관리하기 위해 사용했습니다.
- **ScriptableObject 데이터**: 검·도끼 장비와 상점 효과·업그레이드 값을 코드와 분리해 밸런스 조정을 쉽게 하기 위해 구성했습니다.

## 안내

제외된 에셋과 SDK의 권리는 각 제작자 및 라이선스 제공자에게 있습니다. 이 저장소는 해당 파일의 재배포나 실행용 프로젝트 제공을 목적으로 하지 않습니다.
